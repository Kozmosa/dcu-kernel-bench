Device code includes hip/hip_runtime.h. The figures below were measured on one host of this class; treat them as advisory budgets, not vendor specifications.

- Wavefront is 64 lanes (torch reports warp_size=64). A 32-lane assumption idles half the wave.
- Static shared memory per block is 65536 B. A request for 98304 B fails at compile time with the message that local memory exceeds the limit of 65536. Keep tiles inside 64 KiB or split the reduction across blocks.
- Reported resources: 120 compute units, 4 SIMDs per unit, 40 resident waves per unit, 2560 work-items per unit, workgroup limit 1024, 8 MiB L2, 1400 MHz clock, about 64 GiB of device memory.
- Measured copy bandwidth with a float4 grid-stride kernel is about 688 GB/s. This is a probe number, not a vendor peak: different access widths and occupancies move it by a large factor, so compare only measurements taken with the same probe.

Shared storage and block barriers remain block-scoped. Not measured on this class: matrix-engine throughput, LDS bank count, per-thread register limit, MFMA shapes and asynchronous-copy support; read those from the installed compiler and device rather than assuming values from other accelerators. On the mirror image used for the earlier 80-unit target the same shared-memory and wave-size limits held, so those two do not discriminate between the two classes.
